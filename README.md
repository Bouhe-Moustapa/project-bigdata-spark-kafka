# Soccer Match Analytics - Apache Spark & Kafka ⚽

This project is a complete football match data analytics application using **Apache Spark (Structured Streaming)** and **Apache Kafka**. It demonstrates how to process, clean, model, and analyze real-time data streams to generate sports statistics.

## 📂 Project Structure

The folder nomenclature has been customized to clearly organize the data, scripts, and analysis results:

* **`data/`**: Directory containing source data and related files.
  * `ready_data/`: Cleaned and ready-to-use data.
  * `kafka_data/`: Data related to Kafka ingestion.
  * `saved_models/`: Saved Machine Learning models.
* **`outputs/`**: Processing and analysis results.
  * `exported_dataset/`: Final dataset (in Parquet format) merging historical and scraped data.
  * `processed_output/`: Intermediate results from different processing stages.
  * `model_exports/`: Exported models after the training phase.
  * `stream_results/`: Real-time analysis results via Spark Streaming (rankings, goal statistics).
* **`notebooks/`**: Jupyter Notebooks for exploration, data preparation, and Machine Learning.
  * `prepare_data.ipynb`: Cleaning, preparing, and merging historical and recent data.
  * `train_model.ipynb`: Training a predictive model (e.g., Random Forest) to analyze match results.
* **`src/`**: Python source code for the streaming pipeline.
  * `producer.py`: Kafka producer that reads the Parquet dataset (`outputs/exported_dataset`) and simulates a real-time stream of match events (JSON).
  * `stream_job.py`: Spark Structured Streaming job that consumes Kafka events and calculates live championship statistics.
* **`checkpoints/`**: Checkpoint files generated by Spark Structured Streaming to ensure fault tolerance.

## 🚀 Main Features

1. **Data Preparation**: Processing a large championship match dataset (2007 to 2025).
2. **Real-Time Stream Simulation**: Using a Python Kafka Producer to send match events with a simulated delay, mimicking live matches.
3. **Continuous Analysis with Spark Streaming**: The Spark job dynamically calculates:
   - The **Points Table** (Ranking by points: wins, draws, losses).
   - **Goal Statistics** (goals scored and conceded by team).
   *(These calculations integrate advanced concepts like Watermarking and Tumbling Windows).*
4. **Machine Learning**: Predictive modeling via PySpark ML to deepen team analysis.

## 🛠️ Prerequisites

- **Apache Spark** (v3.5.x recommended)
- **Apache Kafka**
- **Python 3.x** with the following dependencies: `pyspark`, `pandas`, `confluent_kafka`
- **Jupyter Notebook** or JupyterLab

## ▶️ How to Run the Project

### 1. Prepare the Data
Open and run the `notebooks/prepare_data.ipynb` notebook. This will clean the initial dataset (CSV) and generate the merged dataset in `outputs/exported_dataset`.

### 2. Start the Kafka Stream (Producer)
From your terminal, launch the Kafka producer to start broadcasting matches:
```bash
python src/producer.py
```
*(You can define the `KAFKA_BOOTSTRAP_SERVERS`, `KAFKA_TOPIC`, and `MESSAGE_DELAY` environment variables if your configurations differ from the defaults).*

### 3. Launch Real-Time Analysis (Spark Streaming)
Run the Spark job to consume and analyze the Kafka stream:
```bash
spark-submit \
    --master spark://<your-spark-master>:7077 \
    --packages org.apache.spark:spark-sql-kafka-0-10_2.12:3.5.3,org.apache.kafka:kafka-clients:3.5.1 \
    src/stream_job.py
```
The results will automatically be written as they are processed into `outputs/stream_results/`.

### 4. Train the Machine Learning Model
Execute `notebooks/train_model.ipynb` to train the model on your prepared data and export the results to `outputs/model_exports/`.
